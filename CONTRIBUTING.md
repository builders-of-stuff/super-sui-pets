# Contributing to Super Sui Pets

Thank you for your interest in contributing to Super Sui Pets!

## Style Guide

Please follow our coding style guide when contributing to this project. The style guide covers file naming conventions, code organization, and naming patterns.

**Read the full style guide:** [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md)

## Quick Reference

- Use **kebab-case** for all files and folders
- Follow file suffix conventions (`.store.svelte.ts`, `.remote.ts`, `.type.ts`, etc.)
- Use **camelCase** for variables and functions
- Use **SCREAMING_SNAKE_CASE** for constants
- Use **PascalCase** for types and interfaces
- Run `npm run format` before committing to ensure consistent formatting
- Run `npm run lint` to check for linting issues

## Getting Started

1. Fork the repository
2. Create a new branch for your feature or fix
3. Make your changes following the style guide
4. Test your changes locally
5. Submit a pull request

That's it! We appreciate your contributions.
